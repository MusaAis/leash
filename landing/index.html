Bylaw
Built for NEAR HACKATHON

Give AI money. Keep the rules.

Bylaw holds an agent's funds in a vault contract on NEAR. The agent can only ask the vault to pay. The vault enforces the owner's limits on-chain, so a tricked or hijacked agent cannot move money outside its policy.

Try the Arena View the code

How it works

The owner sets the rules

Funds sit in the vault. Each agent gets a policy: a cap per payment, a daily cap and an allowlist of accounts.

The agent asks

The agent holds only gas money. It calls the vault to pay and never holds the funds or the rules.

The vault decides

Allowed payments move. Denied ones are recorded on-chain with a reason. The owner can pause one agent or all of them at any time.

Try to break it

A live agent holds a testnet vault and may pay one payee only. Send it any message. The Arena counts two numbers: how often the agent is fooled, and how much money is lost.
